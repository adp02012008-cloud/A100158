# 🚀 Bug Slayers Dashboard - Web App (PWA) Guide

This application is built as a **Progressive Web App (PWA)** with an interactive **"Install as App"** popup prompt.

---

## 📱 How the "Install as App" Feature Works

The website automatically prompts users to install the dashboard onto their home screen or desktop:

### 1. In-App Install Banner
When a user opens the site in a supported browser (Chrome, Edge, Android Chrome), the app displays a modern floating banner:
> **📱 Install Bug Slayers App** — *Get faster access & offline support on your mobile device* `[Install App]`

### 2. Browser Installation
- **On Android (Chrome / Brave / Edge):** Click the "Install App" button in the bottom banner or tap the browser menu (⋮) -> **"Install app"**.
- **On iPhone / iPad (iOS Safari):** Tap the **Share** button -> Tap **"Add to Home Screen"**.
- **On Desktop (Chrome / Edge):** Click the **Install** icon in the browser address bar or click "Install App" in the banner.
